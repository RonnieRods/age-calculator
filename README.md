# age-calculator
Creating an age calculator using HTML, CSS and JavaScript with use of external packages using npm.

The user inputs their birthdate via a <em>JavaScript Datepicker</em>, and the form calculates and displays their exact age, including years, months and days, using <em>Luxon</em>.

Full details of the project is linked here: [Age Calculator](https://roadmap.sh/projects/age-calculator)

# Project Requirements
- A form that allows users to input their birthdate using a JavaScript datepicker (avoiding the default HTML date picker)
- Use the <em>Luxon</em> library ot calculate the exact age in years, months and days
- Display the result on the same page after the user submits the form
- Implement basic validation to ensure the birthday is valid
- Use simple styling to make the calculator visually appealing and responsive
